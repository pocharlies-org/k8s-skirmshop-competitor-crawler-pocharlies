## RSO Stock-Strip Fix (2026-06-24 rho-backend scope fix)

### Problem
Smoke artefact contained `availability: http://schema.org/InStock` in all products.  
F1 is catalog+price only; stock visibility is F2 scope.

### Change
`src/adapters/base.py` - `_normalize()` now strips eight stock/availability keys before returning product dict:  
`availability, stock, stock_status, quantity, qty, in_stock, out_of_stock`  
Defined as class-level frozenset `_F1_STOCK_FIELDS`.

`tests/test_adapters.py` - new test `test_normalize_strips_f1_stock_fields` verifies raw dict with all 7 stock fields produces a product dict with none of them present.

## Microdata Availability Cleanup (2026-06-24 rho-backend scope fix #2)

### Problem
F1 diff in `src/extractor.py` microdata branch added `avail = item.find(itemprop="availability")` and `"availability": ...` in the product dict. F1 must not implement raw stock extraction; stock visibility is F2 scope. Although `_normalize` in `base.py` strips it post-extraction, the extraction itself violates F1 scope.

### Change
`src/extractor.py` microdata branch: removed `avail = item.find(itemprop="availability")` and the `"availability": ...` key from the microdata product dict. `image` and `description` retained. JSON-LD path (`_from_jsonld_product`) unchanged (pre-F1, stripped by `_normalize` anyway).
